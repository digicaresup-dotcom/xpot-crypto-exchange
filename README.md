# XPOT - Digital Currency Exchange (MVP)

This repository contains the frontend scaffold for the XPOT crypto exchange MVP.

Features included in this branch (feature/xpot-mvp):

- React + Vite frontend
- TailwindCSS configured
- Landing page converted from the provided HTML
- Simple simulated live market data

Next steps (to be added):

- Supabase integration for auth and database
- Stripe test wiring for fiat deposits
- Dashboard, Wallet, Support and Admin pages
- Seeded demo users and data
- CI/CD and deployment configuration

Local development

1. Install dependencies

   npm install

2. Start dev server

   npm run dev

3. Open http://localhost:5173
